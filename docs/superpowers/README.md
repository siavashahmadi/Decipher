# docs/superpowers

Historical spec and plan artifacts from the author's AI-assisted
workflow. Kept in the repo as a record of how the app evolved across
phases, not as reference documentation for the running app.

- `plans/` — phase-by-phase implementation plans (phase 2 backend
  correctness, phase 3 visual polish, phase 5 solve management, phase
  6 stats expansion, phase 7 export, and the original `revamp.md`).
- `specs/` — longer-form specifications kept alongside plans.

If you are reading the codebase to understand how the app works, start
at the top-level `README.md`, `AUDIT_SPEC.md` for the current audit
followup, or `docs/ARCHITECTURE.html` / `docs/ENGINEERING_NOTES.html`.
The contents of this folder are not maintained to match the current
code.
